# firmware-20260916 — IMU 0x0206

适用于本仓库的 CH32V203C8U6（CH32V20x_D6、8 MHz 外部晶振）+
LSM6DSV16X IMU/电源板。此版修复合并读取失联和角速度量程不匹配，保留原有
12 字节采样布局、ID 200 和 1 Mbps 默认通信设置。

## 修复

- DMA 环形缓冲区末端索引导致旧请求循环重放，以及 UART 首包最后字节被截断。
- Dynamixel 2.0 填充、Length、CRC 顺序，以及坏帧后的恢复和状态回显处理。
- 陀螺显式配置为 ±500 dps，与 robotd 的 17.5 mdps/LSB 换算一致。
- 名义采样率配置为 120 Hz；计数仅随新融合数据增加，报告实际采集年龄。
- 启用芯片 SFLP 零偏估计，按其固定 125 dps 单位换算后修正输出角速度。
  原始角速度和偏置仍可只读查询；姿态不做调平或安装方向补偿。
- 保留 SFLP_ODR 必须为 1 的寄存器位，完善四元数有效性和 binary16 编码边界。

## 验证

- 官方 MounRiver RISC-V Embedded GCC 8.2.0，使用仓库随附 WCH SDK。
- 宿主 Debug 与 UBSan 测试均 5/5 通过，MCU 编译成功。
- 最终固件独立 IMU 读取 3,000/3,000、IMU + 15 舵机合并读取 3,000/3,000，
  读取率 50 Hz；无 CRC、超时或重复回复错误。
- 合并读取最后 10 秒的静态角速度均值约为 X -0.0004、Y -0.0044、Z -0.0361 deg/s。
- BIN 为 14,316 字节；text=14,268、data=48、bss=4,272 字节。

测试时电路板任意摆放且静止，没有发送电机动作指令。SFLP 零偏估计需要收敛；
以上末段均值不代表上电立即达到相同残差。未完成动态转动精度、温度全范围或
机器人运动验收。

详细证据见 [传感器验证](../sensor-validation-2026-09-16.md) 与
