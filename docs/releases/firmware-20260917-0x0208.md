# firmware-20260917-0x0208 — DEBUG UART 原始软总线

适用于本仓库 CH32V203C8U6（CH32V20x_D6、8 MHz 外部晶振）+
LSM6DSV16X IMU/电源板。诊断版本为 `0x0208`。

## 本版变化

- PA9/PA10 DEBUG UART 默认改为固定 1 Mbps、8N1 原始字节桥。
- DEBUG RX 使用 DMA1 Channel 5 + UART IDLE 分帧，单突发最大 512 字节。
- 真实总线字节通过 4,096 字节队列和 DMA1 Channel 4 镜像到 DEBUG TX。
- DEBUG 请求在发送到真实总线的同时进入内部 DXL 解析器，不依赖硬件 TX 回显
  即可访问内部 IMU ID 200；内部状态包原样进入 DEBUG 镜像。
- 新增桥接溢出/回显诊断位、softbus 宿主机测试和 115200 文本 CLI 兼容构建。
- 新增单文件 Python 工具 `tools/dxl_softbus_tool.py`，支持多波特率扫描，以及带
  dry-run、型号/冲突/扭矩/错误检查的舵机 ID/波特率修改。
- 物理总线 RX DMA 环形缓冲扩展为 1,024 字节，避免 512 字节完整回显首尾重合。

## 实机验证

- 正式 BIN 14,324 字节；text 14,276、data 48、BSS 10,304 字节。
- 烧录后程序区完整读回与 BIN 一致，SHA-256：
  `b4f4f92a937f042925bfd321f7eb1e1b2ff490c752aeab0372211442f586b0aa`。
- Windows MSVC Release CTest 6/6 通过；PowerShell 与 CMake MCU 构建生成相同 BIN。
- 内部 IMU 版本 `0x0208`、状态 `0x0003`、`last_error=0`，实测样本约 247.7 Hz。
- 两台 XL330-M288 配置为 ID 1/2、1 Mbps；安全控制表访问 142/142 通过，最终
  torque=0、hardware_error=0。
- `SYNC_READ(124,12,[200,1,2])` 通过 FTDI D2XX 1 ms latency，以 50 Hz 连续
  运行 10 分钟：30,000/30,000 成功，平均延迟 2.89 ms、最大 6.70 ms，IMU
  无连续重复样本，固件诊断无错误。
- Python 工具实机完成 ID/波特率可逆修改和恢复，最终仅 ID 1、ID 2 在 1 Mbps 响应。

尚未覆盖：真实断电持久化、IMU 物理断连恢复、看门狗强制复位、硬件异常帧注入
以及 115200 文本 CLI 实机测试。完整证据见
[0x0208 DEBUG 软总线实机验证](../hardware-softbus-2026-09-17.md)。
