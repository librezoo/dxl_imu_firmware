# firmware-20260924-0x020a — USART2 软总线与统一诊断

适用于本仓库 CH32V203C8U6（CH32V20x_D6、8 MHz 外部晶振）+
LSM6DSV16X IMU/电源板。诊断版本为 `0x020A`。

## 本版变化

- 原始 1 Mbps、8N1 软总线入口从 USART1 PA9/PA10 迁移到 USART2 PA2/PA3。
- USART2 RX/TX 分别使用 DMA1 Channel 6/7；USART3 PB10/PB11 继续连接真实
  Dynamixel 半双工总线。
- USART2 RX PA3 和 USART1 RX PA10 均使用空闲上拉，避免未连接串口输入噪声。
- USART1 PA9/PA10 默认同时提供 115200、8N1 文本维护 CLI，不再需要独立固件。
- `tools/dxl_softbus_tool.py check` 一次完成板内 IMU 采样、总线扫描和 XL330
  电压、温度、扭矩及硬件错误检查。
- 全部工具子命令统一输出彩色 PASS/WARN/FAIL，退出码分别为 0/1/2，并保留
  无颜色机器可读 `RESULT` 末行。
- 扫描正确区分 DYNAMIXEL `0x80` Alert 与低 7 位协议错误，带警告的设备仍能
  被发现和检查。

## 接线与检查

```text
PA2  SOFTBUS_TX -> USB-UART RX
PA3  SOFTBUS_RX <- USB-UART TX
GND             <-> USB-UART GND
baud            = 1,000,000, 8N1

PA9  DEBUG_TX   -> 调试串口 RX
PA10 DEBUG_RX   <- 调试串口 TX
baud            = 115,200, 8N1
```

```powershell
python tools\dxl_softbus_tool.py check --port COMx --ids 0-253 --samples 20
```

工具最终状态和退出码为 PASS/0、WARN/1、FAIL/2；未发现外部设备默认 FAIL，
仅检查 IMU 时添加 `--allow-no-external`。

## 验证

- 正式 BIN 15,956 字节；text 15,908、data 48、BSS 10,436 字节。
- BIN SHA-256：
  `3d132032302cfaab52e658bcc59df0d08435d2abacf9f8401c15d8cce023a51e`。
- 烧录后的 15,956 字节程序区完整读回与 BIN 一致。
- Windows MSVC Release CTest 6/6、Python 自测、PowerShell 与 CMake MCU
  构建全部通过，三个 MCU 构建入口生成相同 BIN。
- USART2 软总线对内部 ID 200 完成普通 `READ(124,12)` 300/300 和
  `SYNC_READ(124,12,[200])` 100/100；诊断版本 `0x020A`、`last_error=0`。
- 综合检查的 IMU 20/20 样本与四元数全部有效，观测更新率约 251.7 Hz，最终
  状态 `0x0003`。
- USART1 115200 CLI 的 `get`、`diag`、`dump-imu`、`dump-errors` 均实机通过。
- 外接 XL330-M288 ID 3 在真实总线 1 Mbps 被扫描并完整读取控制表，验证
  USART2→USART3 请求转发和回复镜像链路。

WCH-Link 调试附着可能临时改变目标 PLL；UART 验收应在退出调试并复位后执行。
尚未覆盖 0x020A 多外设长稳、真实断电持久化、IMU 物理断连恢复、看门狗强制
复位和硬件异常帧注入。累计证据见 [验证记录](../validation.md)。
