# firmware-20260918-0x0209 — DEBUG RX 空闲上拉修复

适用于 CH32V203C8U6（CH32V20x_D6、8 MHz 外部晶振）+ LSM6DSV16X IMU/电源板。
本版修复 DEBUG RX 空闲时收到伪字节、经透明桥回灌到 DXL 总线的问题。

## 修复

- 将 PA10 从浮空输入改为内部上拉，保持 UART 空闲高电平。
- 诊断版本更新为 `0x0209`。透明桥和原始字节转发功能保留。
- IMU 名义 240 Hz、主控 50 Hz、ID 200、1 Mbps、坐标和比例换算均不变。

同一接线下，仅改变输入模式即消除故障；重新烧回原版并完整复位后，200 Hz 的前
5 次请求全部失败。GPIO/RAM 对照及详细结果见 [修复验证](../debug-rx-idle-fix-2026-09-18.md)。

## 验证范围

- 从提交源码构建，使用官方 MounRiver GCC 8.2.0 及仓库自带 WCH SDK。
- BIN 14,328 字节，程序读回一致，配置页保留。
- Debug、UBSan 测试各 6/6，软总线工具自检通过。
- 50 Hz、IMU + 15 舵机、600 秒：30,001/30,001 成功，零错误、零跳周期，
  P99 7.599 ms，最大 7.811 ms。
- 单 IMU 200 Hz、60 秒：12,000/12,000 成功。
- IMU 平均 200 Hz + 舵机 50 Hz、60 秒：12,000/12,000 成功。
- 静态采样 1,000/1,000，四元数均有效；融合更新约 251.29 Hz，年龄 0–3 ms。
- 诊断状态保持 3、错误码保持 0，原桥接告警未复现。

整组设备的 200 Hz 仍受事务耗时限制，实际约 148 Hz；混合读取的 200 Hz 是平均值。
全部实物验证为只读，没有电机动作，也不代表动态精度、运动安全或所有外部 DEBUG
适配器电气条件已验收。旧版 [0x0208 发布说明](firmware-20260917-0x0208.md) 保留历史范围。
