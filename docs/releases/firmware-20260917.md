# firmware-20260917 — IMU 0x0207

适用于本仓库的 CH32V203C8U6（CH32V20x_D6、8 MHz 外部晶振）+
LSM6DSV16X IMU/电源板。本版将传感器内部名义更新率从 120 Hz 提高到 240 Hz；
主控与 policy 的 50 Hz 时基不变。

## 本版变化

- 加速度、陀螺及 SFLP 融合使用 240 Hz 档位，诊断版本更新为 `0x0207`。
- 更新初始化读回检查，确认 CTRL1/CTRL2 为 `0x07`、SFLP_ODR 为 `0x63`。
- 保留 ±500 dps / 17.5 mdps/LSB、SFLP 零偏修正、12 字节采样布局、
  ID 200、1 Mbps 以及既有 `SYNC_READ` 支持。
- 保留 0x0206 的总线收发、数据新鲜度及配置保护修复。姿态不做调平或安装方向补偿。

240 Hz 是芯片的名义配置值，本板实测约 251 Hz。该设置不是精确 200 Hz，也不意味着
主控以 240 Hz 读取。合并读取让 IMU 和舵机归入同一轮事务，不保证物理采样时刻完全一致。

## 验证

- 官方 MounRiver RISC-V Embedded GCC 8.2.0，使用仓库随附 WCH SDK。
- 重新构建 MCU 镜像成功；宿主 Debug 与 UBSan 测试均 5/5 通过。
- 静态 IMU 采样 1,000/1,000 成功，四元数均有效，诊断数据年龄 0–3 ms。
- 50 Hz、IMU + 15 个舵机持续合并读取 600 秒：30,001/30,001 成功，
  零通信错误、零调度跳周期；平均 7.116 ms，P99 7.598 ms，最大 8.114 ms。
- 主控最终构建再测 120 秒合并读取：6,001/6,001 成功；14 次串口重开期间
  1,501/1,501 成功，均恢复 IMU 就绪。
- 采样就绪后未丢失就绪状态，最长连续重复数据为 1 次；未达到已有冻结告警条件。
- BIN 为 14,316 字节；text=14,268、data=48、bss=4,272 字节。

测试时电路板任意摆放且静止，没有发送电机动作指令。未完成动态转动精度、
温度全范围或机器人运动验收；SFLP 零偏估计仍需要上电收敛。
